# GearList

A WoW Forever addon that turns a gear set from [sixtyupgrades.com/forever](https://sixtyupgrades.com/forever) into an in-game checklist.

## Importing a set

1. On the site, open your set and click **Export**. Copy all of the text.
2. In game, `/gearlist import` (or the Import button in the list window).
3. Click in the box and press Ctrl+V.
4. Pick the character under **Apply to**, change the list name if you want, and click Import.

The character can be any the addon has been logged in on, the one named in the export, or a name you type. A list filed under a typed name moves to the real character the first time you log in on it. Importing a list with the same name as an existing one replaces it and keeps your hand ticks on slots that didn't change.

## The checklist

One line per slot: the slot, the item, an icon for the kind of source, the details (where it is, or where it comes from while it's missing), what it costs (gold, or token amounts with their icons), the reputation it needs, and its enchant. Click a column's name to sort by it and again to reverse; Slot puts the character-sheet order back. Right-click a column's name to filter by it (a kind of source, a dungeon, a currency, a faction, enchants still to do...). Filters on several columns combine and aren't saved. A ring or trinket counts in either of its two slots. Right-click the item half or the enchant half of a row to tick it by hand. Shift-click links the item, Ctrl-click tries it on. Hover a row for the full detail.

A small icon left of the source says what kind it is: skull for a boss or creature, quest mark for a quest (the text is then just the quest's name), vendor bag or the currency's icon for a vendor, the profession's icon for crafted gear, a chest, a bag for a world drop, a gold coin for a bind-on-equip item.

## The Dungeons tab

Swaps the list for the missing items by dungeon. The dungeon with the most items you still need is at the top, and under each dungeon are its bosses, in the dungeon's own order, with the item each one drops. Quest rewards come after the bosses. A line at the bottom counts the missing items that don't come from a dungeon. Needs the DungeonJournal addon.

## Where the information comes from

| Shown | Where it comes from |
|---|---|
| Vendor cost: gold, currencies, token items, and how many you have | A built-in table of every vendor-sold weapon and armor piece of uncommon quality or better (about 2,000 items), plus whatever a merchant window shows you, which is remembered for the whole account and wins over the table |
| Recipe, skill, pattern seller, materials with prices | CraftRoute's recipes, Auctionator's prices |
| Dungeon boss or quest | DungeonJournal's loot tables |
| Quest rewards anywhere, drops outside those dungeons, world drops, who sells an item | Questie's database |
| Auction price for bind-on-equip items | Auctionator |
| Reputation and profession requirements, red while unmet | The item's own tooltip |

Each of those addons is optional. The export itself only names the items. Common (white) vendor gear isn't in the built-in table, and neither is anything added to the game after it was built; those show no cost until one of your characters has opened the vendor.

## Updating the vendor table

`Data/Vendors.lua` is generated by `python tools/vendors/build.py` from the files in `tools/vendors/`, all saved from Wowhead's Forever database:

- `gear.txt`: the item lists filtered to "Sold by vendor" (`?filter=92;1;0`), weapons and armor, uncommon and better. With that filter each row carries its price and seller. A list shows 1,000 rows at most, so it's read in slices (by quality, and rare armor also by required level). The file's header lists the pages and the line format.
- `*.json`: the "Currency for" list on each currency's page (wowhead.com/forever/currencies). These supply the currency names and win where both have an item.

Wowhead answers a scripted fetch of its pages with a bot check, so the pages were opened one at a time in a browser and read from there.

## Commands

- `/gl` (or `/gearlist`, `/glist`): the list
- `/gl import`: the paste window
- `/gl config`: settings

## Tests

`python tools/test/run.py <folder holding lupa>` loads the addon against a mock of the game's API and checks the import, the gear check and the sources.
